# 🎮 FGhub – Film & Game Hub

FGhub is a full-stack web application designed to manage and explore movies and games in one place. It allows users to browse, rate, and organize media content with a modern and user-friendly interface.

---

## 🚀 Features

- 🎬 Manage Movies and Games in one platform
- ⭐ Rate media with dynamic average rating system
- 📊 View ratings and statistics
- 🔐 User authentication (Login / Signup)
- 🗂 Organized media listing
- ⚡ Responsive and clean UI
- 🔄 Real-time data fetching from backend API
-  🤖 Integrated AI Agent for smart assistance

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- CSS / Custom Styling

### Backend
- Java (Spring Boot)
- REST API

### Database
- MongoDB (or your DB – update if needed)
